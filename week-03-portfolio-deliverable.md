## 3. Identity Kit

### Fonts
- **Heading**: Space Grotesk (Google Fonts, 500 weight)
- **Body**: Inter (Google Fonts, 400 weight)
- **Code**: JetBrains Mono (Google Fonts, monospace)

### Palette
- **Background**: #000000 (near-black)
- **Text**: #FFFFFF (near-white)
- **Accent**: #2DD4BF (mint green)
- No secondary colors — just these three for absolute clarity

### Logo / Favicon
- **"AA" monogram** in angle-bracket code style (`<A>`)
- Matches the mint accent color
- Favicon: single-letter "A" in mint on black

### Style Note
*Quiet, code-focused, intentional. The dark background and single mint accent make the work (screenshots, case studies, code examples) the loudest thing on every page. Space between elements is generous. Nothing animated or decorative — the design frames the work, never upstages it.*

## 4. Image Curation & Rejection Notes

### Images Kept (Real Captures)

1. **WorkHive Hero / Landing Page Screenshot**
   - Clean, legible, shows the actual product
   - Reason: Real work beats any generated image

2. **WorkHive Resume Upload + AI Feedback Section**
   - Shows the AI analyzer in action
   - Reason: Concrete proof of the feature

3. **Diagonal-Lines Hero Texture** (AI-generated, consistent style)
   - Soft, parallel lines fading smoothly
   - Used as background texture connective tissue
   - Reason: Intentional, matches the "quiet confidence" mood

### Images Rejected

**Circuit Pattern**
- *Rejected because: Too simple. The angular lines and nodes read as a generic circuit board, not specific to this work. Doesn't add intentionality — it distracts.*

**Dot-Grid Texture**
- *Rejected because: Too generic. A quiet dot grid could be any startup's texture. Lacks personality and feels like it's trying too hard to be minimal. The diagonal lines feel more deliberate and connected to the code-monogram identity.*

**Glossy Gradient Blob** (the "AI slop" option)
- *Not seriously considered. The melted, overlapping ellipses with soft gradients scream generic AI output. No intentionality. Immediate reject.*
